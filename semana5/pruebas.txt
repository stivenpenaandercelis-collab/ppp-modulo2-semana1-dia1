Ruta http://localhost:3000 -> El servidor responde con el texto "Servidor activo", confirmando que está encendido y respondiendo en la raíz.
Ruta http://localhost:3000/saludo -> El servidor responde con el texto "Hola comunidad", que es un mensaje estático programado en esa ruta específica.
Ruta http://localhost:3000/mensaje/juan -> El servidor lee el parámetro dinámico ":nombre" de la URL (en este caso "juan") y responde "Hola juan". Si cambias "juan" por cualquier otro nombre en la barra de direcciones, el saludo cambiará automáticamente.
